# ТЗ: Веб-приложение «GtG Tracker» (PWA)


- https://alexander-topilskii.github.io/GtgTracker/


Минималистичный мобильный PWA-трекер для распределенных микротренировок по методологии Grease the Groove (GtG).

> 📋 **Поэтапный план разработки и дорожная карта проекта:** [plan/README.md](file:///Users/aleksandrtopilskii/Documents/projects/gtgTracker/plan/README.md)

## 1. Общие требования и стек

- **Стек:** TypeScript, React (или Vue 3), Tailwind CSS, Vite, WebGL / GLSL (Canvas/Three.js/Ogl для легковесных шейдеров), Lucide Icons, Motion (Framer Motion или Motion One).
- **Хостинг:** GitHub Pages (SPA с base path репозитория).
- **Архитектура данных:** Local-first. Все данные сохраняются исключительно в `localStorage` (или IndexedDB) браузера пользователя. Без бэкенда. Программа тренировок хранится в формате JSON; история тренировок иммутабельна и изолирована от будущих изменений программы.
- **Форм-фактор:** Mobile-first, адаптивная верстка (фокус на экраны смартфонов 360–430px шириной, без вертикального скролла на главном экране — 100dvh).
- **PWA:** Поддержка `manifest.json` и Service Worker для работы офлайн и установки на домашний экран iOS/Android (standalone mode).

## 2. Дизайн, UI/UX и визуальные эффекты

### 2.1. Философия стиля: Кибер-минимализм (Stealth & Glow)
- **Цветовая палитра:** Глубокая темная эстетика (OLED Black `#08090d`, графитовые слои карточек `#12151f` с полупрозрачными рамками `1px border border-white/5`).
- **Световые акценты (Luminescent Accents):** Акцентный неоновый изумрудный (Cyber Emerald `#10b981`), неоновый голубой (Electric Cyan `#06b6d4`) и предупреждающий янтарный (`#f59e0b`).
- **Типографика:** Контрастная связка — плотный современный гротеск (Inter / Plus Jakarta Sans) для текста и футуристичный моноширинный шрифт (JetBrains Mono / Space Mono) для таймеров, счетчиков и подходов.
- **Эргономика (Thumb-Zone):** Все интерактивные элементы расположены в зоне досягаемости большого пальца; крупные зоны тапа (от 48px), исключение случайных кликов.

### 2.2. Шейдерные эффекты (WebGL / GLSL / Canvas)
- **Живой субтильный фон (Ambient Noise Aura):**
  - Полноэкранный легковесный фоновый GLSL-шейдер (на базе Canvas или WebGL).
  - Генерирует медленное, ультрамягкое органическое движение градиента шума (Perlin / Simplex noise).
  - Реагирует на статус готовности: в фазе отдыха фон холодный, сдержанный графитово-синий; по истечении 45–60 минут по краям мягко разгорается изумрудная пульсирующая аура (ready-state indicator), интуитивно подсказывающая, что мышцы восстановились.
  - Оптимизирован по энергопотреблению: низкая частота сэмплов, автоматическая пауза анимации (`requestAnimationFrame`) при неактивной вкладке (Page Visibility API).
- **Шейдерный таймер готовности (Radial Glow Gauge):**
  - Индикатор времени отдыха с круговым или дуговым шейдерным свечением.
  - Поверхность индикатора отображает плавный пробегающий световой блик (specular sweep) и эффект «дыхания» (soft radial bloom), нарастающий к 100% готовности.
- **Эффект нажатия (Liquid / Refraction Ripple):**
  - При тапе по кнопке быстрой фиксации подхода (`+1`) от точки касания расходится микроволна светового преломления/свечения (refractive ripple), создающая ощущение физической упругости интерфейса.
- **Тактильная зернистость (Film Grain / Dither Shader):**
  - Легкий шейдер процедурного шума (2–3% opacity), устраняющий цветовую постеризацию на темных градиентах и придающий карточкам бархатистую материальность.

### 2.3. Микроанимации и кинетика интерфейса
- **Физика упругости (Spring Physics):** Пружинистый масштабный отклик кнопок при нажатии (`scale(0.96) -> scale(1.02) -> scale(1.0)` с физикой затухания).
- **Индикаторы подходов (Pip Fill & Burst):**
  - Слоты выполненных подходов (`[●][●][○]`) загораются с плавной вспышкой неонового свечения (glow flash) и микро-заполнением.
  - При закрытии финального подхода упражнения (например, 5/5) — локальный микро-взрыв неоновых искр (particle burst).
- **Плавные счетчики (Odometer / Rolling Numbers):**
  - Цифры таймера и количества повторений перелистываются плавной кинетической прокруткой без резких скачков.
- **Сенсорный виброотклик (Web Vibrations API):**
  - Легкий щелчок (`8–10 ms`) при обычных кликах и переключениях.
  - Глубокий отчетливый импульс (`35 ms`) при фиксации подхода.
  - Двойной триумфальный импульс (`[20ms, 40ms, 40ms]`) при закрытии всех упражнений за день.

## 3. Базовая логика и структура данных

### 3.1. Хранение программы тренировок в JSON и защита исторических записей
- **Декларативная JSON-конфигурация программы:**
  - Полная программа тренировок (типы дней, список упражнений, целевые подходы, дефолтные повторения, рабочий вес) хранится в формате JSON (`program.json`).
  - Проект поставляется с дефолтным JSON-планом, который пользователь может кастомизировать или полностью заменить в настройках.
- **Принцип иммутабельности истории (Historical Immutability & Snapshotting):**
  - **Критическое требование:** Любые будущие изменения программы (добавление/удаление упражнений, изменение целевых нормативов, смена дней недели) **ни при каких обстоятельствах не аффектят старые записи**.
  - **Механизм снапшотов:** В логах тренировок (`DayRecord` / `ExerciseLogItem`) сохраняется снимок метаданных на момент выполнения (`exerciseNameSnapshot`, `targetRepsSnapshot`, `targetSetsSnapshot`).
  - При просмотре истории за любую прошлую дату интерфейс отображает данные ровно так, как они были зафиксированы в тот день, даже если упражнение было переименовано или удалено из текущей программы.
  - Удаление упражнения из активного плана является «мягким» с точки зрения истории (упражнение просто перестает появляться в будущих днях, но остается в исторической базе).

### 3.2. Базовая модель тренировочного плана (дефолтный конфиг)

Два чередующихся дня:

- **День А (Верх — База):**
  - Подтягивания (Pull-ups) — цель: 5 подходов
  - Отжимания на брусьях (Dips) — цель: 5 подходов
  - Подъем ног к перекладине (Hanging Leg Raises) — цель: 3–4 подхода

- **День Б (Руки, Плечи, Ноги):**
  - Подъем гантелей на бицепс (Bicep Curls) — цель: 4–5 подходов
  - Махи с гантелями в стороны/вперед (Lateral/Front Raises) — цель: 4–5 подходов
  - Приседания (Squats / Bulgarian Split) — цель: 5 подходов

- **День отдыха (Воскресенье или по выбору):** Статус паузы.

### 3.3. Схема сущностей (TypeScript)

```typescript
export type DayType = 'A' | 'B' | 'REST' | string;

// Конфигурация отдельного упражнения в программе
export interface ExerciseConfig {
  id: string;
  name: string;
  targetSets: number;
  defaultReps: number;
  weight?: number; // опционально для гантелей
}

// План конкретного тренировочного дня
export interface DayPlanConfig {
  dayType: DayType;
  title: string;
  exercises: ExerciseConfig[];
}

// Корневая конфигурация программы тренировок (хранится в JSON)
export interface WorkoutProgramConfig {
  version: number;
  name: string;
  defaultRestIntervalMinutes: number; // по умолчанию 60 минут
  days: Record<DayType, DayPlanConfig>;
}

// Запись о выполненном подходе со снапшотом метаданных
export interface ExerciseLogItem {
  id: string;
  exerciseId: string;
  exerciseNameSnapshot: string; // Имя упражнения на момент фиксации
  timestamp: number; // Date.now()
  reps: number;
  weight?: number;
}

// Запись о тренировочном дне в истории (иммутабельна)
export interface DayRecord {
  date: string; // Формат YYYY-MM-DD
  dayType: DayType;
  completedSets: ExerciseLogItem[];
  programVersionSnapshot?: number; // Ссылка на ревизию программы на момент выполнения
}
```

## 4. Функциональные требования

### 4.1. Главный экран (Dashboard)

- **Индикатор текущего дня:** Отображение текущей даты и типа тренировки (День А, День Б, Отдых) с плавным переключением и неоновым бейджем активного статуса.
- **Шейдерный таймер отдыха с последнего подхода:**
  - Отображает: «С последнего подхода прошло: Х ч. Y мин.» в моноширинном формате.
  - Динамический радиальный/аурный шейдер меняет состояние: холодный приглушенный оттенок при отдыхе -> пульсирующее неоновое изумрудное свечение при готовности мышц (>45–60 минут).
- **Список упражнений на сегодня:**
  - Карточка каждого упражнения в стиле темного стекла (subtle backdrop blur + 1px border):
    - Название и целевой норматив (например, 5 подтягиваний).
    - Индикатор выполненных подходов (например, `[●][●][○][○][○]` — 2/5) с анимацией неонового возгорания слотов и частицами при закрытии сета.
    - Крупная кнопка быстрой фиксации `+1 подход` с пружинистой отдачей (spring press), шейдерной волной нажатия (refraction ripple) и тактильным вибро-импульсом (Haptic Feedback).
    - Долгий тап/клик по кнопке или карточке для быстрой корректировки числа повторений в модальном окне-шторке (bottom sheet).

### 4.2. Экран истории и статистики (History)

- **Минималистичный календарь** с цветовой индикацией закрытых дней (зеленая точка — план выполнен полностью, желтая — частично, серая — отдых).
- **Суммарный недельный объем (Volume Tracker):** общее количество повторений по каждому движению за последние 7/30 дней.

### 4.3. Экран настроек (Settings)

- **Управление программой тренировок:**
  - Редактирование списка упражнений и целевых параметров (кол-во подходов, рабочие повторения, вес) через визуальный интерфейс или встроенный JSON-редактор.
  - Экспорт и импорт файла программы (`program.json`) с валидацией схемы.
  - Гарантия безопасного сохранения: редактирование и смена программы обновляют только будущие тренировки, не затирая и не модифицируя исторические логи.
- Настройка интервала отдыха между подходами для таймера готовности (по умолчанию 60 минут).
- Экспорт / Импорт полной базы данных приложения (программа + история) в единый JSON-файл для бэкапа.
- Кнопка безопасного сброса данных (с подтверждением).

## 5. Деплой и сборка

- Репозиторий на GitHub.
- **GitHub Actions workflow:**
  - Триггер по push в `main`.
  - Шаги: `npm ci` -> `npm run build` -> публикация директории `dist` в ветку `gh-pages` через `actions/deploy-pages`.
- Корректный `base` в конфигурации сборщика (например, `base: '/gtg-tracker/'` в `vite.config.ts`) для корректной подгрузки ассетов на GitHub Pages.
