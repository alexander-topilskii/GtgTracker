# Этап 05: Шейдеры, визуальные эффекты и кинетика (Shaders & Micro-Animations)

## 1. Цель этапа
Оснастить минималистичный интерфейс выразительными высокотехнологичными деталями: легковесными WebGL/GLSL шейдерами фона и таймера, тактильной пружинной физикой нажатий, микро-вспышками и частицами при закрытии подходов, сохранив высокую частоту кадров (60 FPS) и нулевое влияние на батарею мобильного устройства.

---

## 2. Детальный состав работ

### 2.1. Шейдер фоновой ауры (Ambient Noise Aura Shader)
- Создание легковесного WebGL Canvas-компонента `src/components/shaders/AmbientAuraShader.tsx`:
  - GLSL фрагментный шейдер с плавным шумом (Simplex/Perlin Noise).
  - Фон генерирует ультрамягкое, едва заметное «дыхание» темных градиентов.
  - **Динамический переход (Uniforms):**
    - `u_readiness`: коэффициент от 0.0 (отдых, холодный серо-синий ореол) до 1.0 (готовность, мягкая изумрудная пульсирующая аура по краям экрана).
  - Энергосбережение: рендеринг в низком разрешении (scale factor 0.5) с CSS `blur`, пауза цикла рендеринга при сворачивании окна или вкладки (`document.hidden`).

### 2.2. Радиальный шейдер таймера (Radial Glow Gauge)
- Создание шейдерного кольцевого индикатора `src/components/shaders/RadialTimerShader.tsx`:
  - Динамическое заполнение круга прогресса времени отдыха (от 0 до 60 минут).
  - Эффект бегущего светового блика (specular sweep) вдоль дуги индикатора.
  - Мягкий диффузный радиальный bloom при достижении 100% времени отдыха.

### 2.3. Эффект физического нажатия (Liquid / Refraction Ripple)
- Реализация шейдерной микроволны нажатия на кнопках фиксации подходов:
  - При клике от точки тапа расходится короткая волна преломления света (`u_rippleCenter`, `u_time`).
  - Ощущение продавливания тактильной физической кнопки из темного стекла.

### 2.4. Процедурная зернистость (Film Grain / Dither)
- Наложение тонкого шейдерного шума (2–3% непрозрачности) поверх фона:
  - Устраняет артефакты бандинга (ступенчатости) на темных градиентах AMOLED-экранов.
  - Создает эффект бархатистой премиальной текстуры.

### 2.5. Кинетика и пружинные анимации (Motion)
- Подключение `motion` (Framer Motion / Motion One):
  - **Spring-press:** Пружинный масштаб кнопок `whileTap={{ scale: 0.94 }}` с пружинным возвратом.
  - **Pip Fill & Sparkles:** Заполнение индикаторов подходов сопровождается вспышкой свечения.
  - **Particle Burst:** При закрытии 5/5 подходов карточка выпускает сноп миниатюрных неоновых искр (canvas-confetti или кастомные частицы).
  - **Rolling Numbers (Одометр):** Цифры в счетчиках плавно перекатываются при изменении.

## 4. Критерии приемки (Acceptance Criteria)

- [x] **Стабильные 60 FPS:** Шейдер рендерится с разрешением 0.5x с аппаратным размытием, обеспечивая ультра-легкую нагрузку на мобильный GPU.
- [x] **Реакция фона на таймер:** Шейдер `AmbientAuraShader` плавно смешивает холодный серо-синий фон в фазе отдыха с яркой изумрудной аурой по краям экрана при переходе в режим боевой готовности.
- [x] **Энергоэффективность:** При сворачивании вкладки или блокировке телефона (`visibilitychange`) цикл `requestAnimationFrame` мгновенно останавливается.
- [x] **Тактильная пружина:** Кнопки и слоты оснащены пружинной кинетикой `active:scale-95` с быстрым затуханием.
- [x] **Празднование завершения:** Закрытие последнего подхода (5/5) сопровождается микро-вспышкой неоновых частиц `canvas-confetti` прямо из точки нажатия.
- [x] **Отказоустойчивость (Fallback):** В случае отсутствия WebGL компонент безопасно выключается без краша UI.
- [x] **Процедурная текстура:** Добавлен `FilmGrainOverlay` (тонкий шум 3.5%), устраняющий эффект ступенчатых градиентов (color banding) на экранах телефонов.

## 6. Принятые технические решения (ADR)
1. **Кастомный Simplex/Perlin WebGL шейдер:** Разработан процедурный GLSL фрагментный шейдер с плавной интерполяцией переменной готовности `u_readiness`.
2. **Оптимизация рендера:** Шейдер вынесен на фоновый абсолютный слой с `pointer-events-none` и `will-change: transform`.
3. **Локализованные частицы:** Эффект взрыва искр высчитывает координаты `boundingClientRect` нажатой кнопки и выбрасывает частицы точно из центра тапа.
