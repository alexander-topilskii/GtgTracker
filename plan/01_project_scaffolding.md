# Этап 01: Инициализация проекта и каркас приложения (Scaffolding & Core Architecture)

## 1. Цель этапа
Создать базовое работающее React + TypeScript + Tailwind веб-приложение на базе сборщика Vite с поддержкой мобильной верстки (360–430px), темной темы оформления (Cyber-Minimalism) и готовой конфигурацией для деплоя на GitHub Pages. В конце этапа приложение запускается локально (`npm run dev`), компилируется без ошибок (`npm run build`) и отображает базовый рабочий интерфейс-каркас.

---

## 2. Детальный состав работ

### 2.1. Конфигурация Vite и TypeScript
- Инициализация и настройка конфигурации `vite.config.ts` с поддержкой `base: './'` (или с переменной окружения/базовым путем для GitHub Pages).
- Настройка `tsconfig.json` (strict mode, path aliases `@/*` -> `src/*`).
- Установка и настройка Tailwind CSS с поддержкой пользовательских цветов темы (`cyber-black: #08090d`, `card-bg: #12151f`, `neon-emerald: #10b981`, `neon-cyan: #06b6d4`).

### 2.2. Базовая дизайн-система и глобальные стили
- Подключение качественных шрифтов: Inter / Plus Jakarta Sans для интерфейса и JetBrains Mono для числовых значений.
- Создание `src/index.css` с CSS-переменными темы, сбросом скроллбаров, базовым темным фоном и фиксацией вьюпорта под мобильные экраны (100dvh, `overflow-hidden` на главном экране).
- Определение базовых утилит стекломорфизма (`backdrop-blur-md`, `border-white/5`).

### 2.3. Каркас интерфейса (App Shell)
- Создание корневого лейаута `src/App.tsx`:
  - **Header:** Название «GtG Tracker», индикатор статуса, дата.
  - **Main Content Area:** Контейнер для экрана (с фиксированной высотой под мобильный экран без скролла).
  - **Bottom Navigation Bar:** Минималистичная нижняя панель переключения вкладок:
    - 🏋️‍♂️ Тренировка (Dashboard)
    - 📅 История (History)
    - ⚙️ Настройки (Settings)
- Добавление библиотеки иконок `lucide-react`.

## 4. Критерии приемки (Acceptance Criteria)

- [ ] **Рабочая локальная разработка:** Команда `npm run dev` стартует dev-сервер без ошибок и предупреждений в терминале и консоли браузера.
- [ ] **Чистая сборка:** Команда `npm run build` успешно генерирует продакшен-бандл в папку `dist/`.
- [ ] **Мобильный лейаут (Mobile-First):** Интерфейс аккуратно центрирован на экранах десктопа и идеально адаптирован под мобильные устройства шириной 360–430px.
- [ ] **Фиксация высоты 100dvh:** Главный контейнер не вызывает паразитного вертикального скролла на мобильных устройствах.
- [ ] **Работающая навигация:** Нижняя панель позволяет переключать активную вкладку (Dashboard, History, Settings) с визуальным выделением активной кнопки.
- [ ] **Темная тема по умолчанию:** Фон `#08090d`, карточки и кнопки соответствуют утвержденной палитре Stealth & Glow.

## 5. Проверка работоспособности (No-Regression Check)
1. Выполнить `npm run build` — код компилируется с кодом возврата 0.
2. Открыть в браузере в режиме эмуляции iPhone 13/14 (390x844):
   - Проверить отсутствие вертикального скролла.
   - Проверить клики по табам нижней навигации — активный таб переключается мгновенно.
