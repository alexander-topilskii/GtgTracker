# Этап 04: Таймер отдыха и индикатор готовности мышц (Rest Timer & Muscle Readiness)

## 1. Цель этапа
Реализовать блок таймера отдыха на главном экране, отображающий точное время, прошедшее с момента последнего выполненного подхода в любом упражнении текущего дня, с динамической цветовой индикацией готовности мышц к новому подходу (методология Grease the Groove).

---

## 2. Детальный состав работ

### 2.1. Логика расчета интервала отдыха
- Поиск самого свежего `timestamp` среди всех выполненных подходов за сегодня (`Math.max(...completedSets.map(s => s.timestamp))`).
- Если за сегодня подходов еще не было: отображение нейтрального статуса «Готов к первому подходу» или времени с начала дня.
- Хук `useRestTimer(lastTimestamp, targetRestMinutes)`:
  - Периодический таймер (интервал 1–10 секунд для точного расчета).
  - Форматирование: «С последнего подхода прошло: Х ч. Y мин.» в моноширинном виде (`font-mono`).
  - Учет Page Visibility API: при переключении обратно на вкладку немедленный пересчет разницы во времени без залипания.

### 2.2. Состояния и цветовая индикация готовности (State Machine)
- **Состояние 1: Восстановление (<45 минут):**
  - Цвет: Сдержанный серый / холодный Slate (`text-zinc-400`).
  - Статус: «Восстановление ЦНС и мышц...»
- **Состояние 2: Приближение к готовности (45–59 минут):**
  - Цвет: Теплый янтарный / мягкий аквамарин (`text-cyan-400`).
  - Статус: «Почти готово к новому подходу».
- **Состояние 3: Боевая готовность (>=60 минут / настраиваемый порог):**
  - Цвет: Насыщенный неоновый изумрудный (`text-emerald-400`, `shadow-emerald-500/30`).
  - Статус: «Мышцы готовы к подходу! 🔥»
  - Пульсирующий индикатор-точка.

### 2.3. Интеграция в лейаут главного экрана
- Размещение виджета таймера над списком карточек упражнений.
- Компактный эргономичный размер, не смещающий карточки за пределы первого экрана.

## 4. Критерии приемки (Acceptance Criteria)

- [x] **Точный расчет времени:** Таймер показывает корректное количество часов и минут с момента последнего нажатия кнопки `+1 подход`.
- [x] **Реакция на фиксацию подхода:** Сразу после нажатия кнопки `+1` в любом упражнении таймер мгновенно сбрасывается в `0 мин` и переходит в статус «Восстановление».
- [x] **Цветовая трансформация:**
  - При времени < 45 минут таймер отображается в приглушенных серых тонах.
  - При приближении (45–59 мин) подсвечивается циановым свечением.
  - При времени >= 60 минут таймер подсвечивается неоновым изумрудным цветом со статусом «Мышцы готовы к подходу! 🔥».
- [x] **Корректность после сворачивания:** Использован `document.addEventListener('visibilitychange')` — при возврате во вкладку время пересчитывается без задержки.
- [x] **Отсутствие утечек памяти:** Интервалы таймера и слушатели событий корректно очищаются при размонтировании.

---

## 6. Принятые технические решения (ADR)
1. **Кастомный хук useRestTimer:** Отделяет бизнес-логику таймера и переходов состояний (IDLE / RECOVERY / APPROACHING / READY) от визуального представления.
2. **Page Visibility API:** Гарантирует абсолютную точность показаний таймера при пробуждении смартфона из фонового режима.
3. **Адаптивный прогресс-бар:** В нижнюю грань виджета встроен неоновый индикатор процента готовности с плавным transition.

---

## 5. Проверка работоспособности (No-Regression Check)
1. Нажать `+1 подход` — таймер обнуляется.
2. Искусственно передать в стор подход с timestamp часовой давности (`Date.now() - 65 * 60 * 1000`):
   - Убедиться, что таймер мгновенно загорается зеленым неоном.
3. Проверить `npm run build` — компиляция без ошибок.
