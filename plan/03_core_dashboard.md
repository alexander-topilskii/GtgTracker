# Этап 03: Главный экран: Dashboard и интерактивные карточки подходов (Core Dashboard)

## 1. Цель этапа
Реализовать основной рабочий экран приложения (Dashboard), позволяющий просматривать тренировку текущего дня, переключать тип дня в один клик и фиксировать выполненные подходы в одно касание (`+1 подход`) с тактильным откликом. Экран спроектирован строго под 100dvh без необходимости вертикального скролла на смартфонах.

---

## 2. Детальный состав работ

### 2.1. Переключатель и индикатор дня (Day Header)
- Отображение текущей даты (например, «Пт, 12 сентября»).
- Интерактивный сегментный переключатель типов дня:
  - `День А (Верх)`
  - `День Б (Низ / Руки)`
  - `Отдых`
- Автоматический выбор дня (чередование А/Б с выходным по воскресеньям) с возможностью ручной смены в 1 тап.

### 2.2. Карточки упражнений (Exercise Cards)
- Карточка упражнения выполнена в стиле темного полупрозрачного стекла (`bg-white/[0.03]`, `border border-white/10`, `rounded-2xl`):
  - Название движения и целевой норматив (например, `5 подтягиваний`).
  - Индикатор выполнения: горизонтальная полоса визуальных пипов/слотов (например, `[●][●][○][○][○]` — 2 из 5 подходов закрыто).
  - Бейдж выполненного объема за сегодня (например, `10 / 25 повт.`).
- **Кнопка быстрой фиксации «+1»:**
  - Высота и ширина от 48px (Touch-friendly zone).
  - Одиночный быстрый тап: мгновенная запись текущего времени (`Date.now()`) и нормативного числа повторений.
  - Визуальное мгновенное заполнение следующего пипа.

### 2.3. Редактирование подхода (Long Press / Bottom Sheet)
- Долгий тап (>400ms) или кнопка настроек на карточке открывает компактную шторку (Bottom Sheet):
  - Возможность изменить количество повторений в данном подходе (например, если сделано 4 вместо 5).
  - Ввод дополнительного веса (для упражнений с гантелями/утяжелителями).
  - Удаление ошибочно добавленного подхода.

### 2.4. Тактильный отклик (Web Vibrations API)
- Утилита `src/utils/haptics.ts`:
  - Проверка поддержки `navigator.vibrate`.
  - Легкий виброотклик (`10ms`) при фиксации `+1`.
  - Отчетливый импульс (`35ms`) при закрытии всех целевых подходов упражнения.
  - Опция отключения виброотклика в настройках.

## 4. Критерии приемки (Acceptance Criteria)

- [x] **Главный экран без скролла:** Весь блок дня с карточками упражнений и элементами управления скомпонован под 100dvh без появления полосы прокрутки.
- [x] **Фиксация в 1 клик:** Нажатие кнопки `+1` мгновенно увеличивает счетчик подходов, окрашивает соответствующий пип и сохраняет запись в `localStorage`.
- [x] **Редактирование по долгому тапу:** При удержании карточки (>450ms) или клике на слайдер открывается `BottomSheet` с возможностью задать произвольные повторения и вес.
- [x] **Корректировка и удаление:** В модальном окне выведен список подходов с точным временем, кнопкой удаления и ручным добавлением.
- [x] **Переключение дня:** Селектор `DaySelector` переключает День А, День Б и экран Отдыха в 1 тап.
- [x] **Тактильный отклик:** Интегрирован `haptic` (Web Vibrations API + синтезатор Web Audio API для iOS Safari).

## 6. Принятые технические решения (ADR)
1. **Эргономика Touch-Target:** Кнопка фиксации подхода занимает всю ширину карточки с высотой от 44–48px и ярким изумрудным градиентом.
2. **Гибридный Haptics:** Реализован кроссплатформенный класс `HapticManager`, использующий `navigator.vibrate` на Android и мягкий синтезированный клик (140->40 Гц за 25 мс) на iOS через Web Audio API.
3. **Мобильная шторка (BottomSheet):** Реализована с блокировкой скролла, поддержкой закрытия по клику на фон или Escape и анимацией подъема снизу.
4. **Индикаторы ProgressPips:** Динамически адаптируют ширину и поддерживают визуализацию экстра-подходов (сверх целевых 5).

## 5. Проверка работоспособности (No-Regression Check)
1. Запустить `npm run dev`.
2. Зафиксировать 3 подхода в первом упражнении:
   - Проверить, что отображается `3/5`.
   - Обновить страницу — убедиться, что `3/5` сохранились.
3. Открыть шторку долгого тапа, изменить 3-й подход на 6 повторений — проверить сохранение в сторе.
4. Проверить отсутствие ошибок в консоли браузера.
